# Inter

Unmodified variable WOFF2 fonts from the [official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), distributed under the included SIL Open Font License.

The root layout loads these files through `next/font/local` and exposes `--font-inter` to the global styles and Tailwind's `font-sans` utility. Fonts are served with the site, so rendering does not depend on locally installed fonts or a third-party font service.
